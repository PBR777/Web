简介

全同论是一种用数学探讨宇宙的理论，致力在哲学与宇宙学间建立联系，从宇宙的角度去解释悖论。

前提
  • 宇宙在空间上是无限的。
  • 宇宙在任意时刻下的总质能必须趋近于无限。
  • 宇宙在任意时刻下的物质分布大体上要是均匀的。

幸运的是，这三大前提在主流宇宙学中均成立。

 理论 物体

物体并不完全是物质，物体指所有动质能不为0的物质（有一个例外），例如水、泥土、氢原子、电子、光子……

物体可以划分为扁平物体和非扁平物体。一个在时间轴上投影的长度为0的物体是扁平物体，不为0则是非扁平物体。

在表示非扁平物体时，需要为符号添加上横线。例如X，铁块的世界超体积……

若物体X为扁平物体，则 tX 用来表示 X 在时空中的时间。

若物体X为非扁平物体，则一般用 X(t) 来表示时刻t下X的扁平物体X。不难看出，我们有 X(tX) = X。

𝟎是一种特殊的物体，在现实中并不存在。我们规定：𝟎既是扁平物体也是非扁平物体，此时𝟎满足 m𝟎 = 0 和 t𝟎 为未定义，-𝟎 = 𝟎，∀t∈ℝ ⇒ 𝟎(t) = 𝟎。

物体集合

𝕆是一个无限集，指物体集合，包含了所有物体。𝕆与物体加法构成𝕆群。

∀X, Y∈𝕆 : Y ≠ X ⇒

  • X - Y ≠ 𝟎;

𝕆是扁平物体集合，满足 𝕆 ⊂ 𝕆。

物体的相加与相减

在𝕆群中，减法（-）是加法（+）的逆运算。

    ∀X, Y∈𝕆，满足：
  • X - X = X + (-X) = 𝟎 和 X + 𝟎 = X - 𝟎 = X;
  • m-X = -mX;
  • mX + mY = mX + Y.

物体加法简单理解为将两个物体组合在一起。例如 玻璃瓶 + 软木塞 = 塞着软木塞的玻璃瓶。

需要注意的是，物体间的加法运算并不考虑X和Y在时空中的重叠程度，最终结果会计重。

一张不太严谨的 X + Y 示意图，当X和Y在时空中部分重叠，X + Y 会“多算”一份重叠的部分。

X - Y 可以理解为，去掉X与Y重叠的部分，然后将剩余的Y“质量反转”。

物体的交集和并集

注意：虽然称呼为交集和并集，甚至连符号都与集合论相同。但物体不是集合，在物体间使用⊂、⊄……是不被允许的。

    ∀X, Y∈𝕆 它们满足：
  • X ⋂ Y = Y ⋂ X 和 X ⋃ Y = Y ⋃ X;
  • X ⋂ Y = X + Y - (X ⋃ Y);
  • X ⋃ Y = X + Y - (X ⋂ Y);
  • X ⋂ 𝟎 = 𝟎 和 X ⋃ 𝟎 = X.

可见，物体的并集会去重。

四种物体运算的示意图 量化差异

XDY 是量化差异函数，用于指示物体之间差异，读作X到Y的差异。这个函数仅仅停留在概念阶段，它并不具备实际的计算方法。

我们定义，量化差异函数只考虑物体的内部状态，而不考虑它们在时空中的位置。

    在 XDY = n 里：
  • X∈𝕆;
  • Y∈𝕆;
  • n∈[0, +∞).

虽然物体间的量化差异没有计算方法，但是通过直觉，我们不难得出：

  • 当 XDY = 0 ⇒ X和Y全同（即完全相同）；
  • 物体X到Y的主观差异越大时 ⇔ XDY 越大；
  • 物体X到Y的主观差异比物体M到N的大 ⇔ XDY > MDN 。

当我们说物体X和物体Y全同时，意味着我们可以通过平移和旋转Y，使得Y与X完全重合：

通过在时空中平移、旋转Y，令Y与X重合。

在宏观层面，X和Y重叠了；在微观层面则更为壮观：Y内部的所有分子的位置，乃至原子、中子、电子的排布都完完全全与X相同，以至于能完全重合在一起。

反过来，当一个物件Y内部的所有粒子排布均与X的相同，那么 XDY = YDX = 0。

实际上，很多看似相同的物体，都不是全同的。两个边长为1cm的立方体铁块，表面看上去没有任何分别，在质量上也感觉不出任何差别。可是它们内部的铁原子排布却几乎不可能全同，所有它们的量化差异也几乎不可能为0。

但是，如果将特殊的粒子作为比较对象，情况又有所不同。例如将两个电子作对比，e-1De-2 将会得到0。这些与彼此的量化差异为0的粒子，正是全同粒子。

如果两个质量较大的物体的量化差异为x，两个质量较小的物体的量化差异为y，由于大质量物体通常拥有更多粒子，其内部的状态数会比小质量物体要高出几个数量级，所以x通常大于y：

In general, ∀ε>0, ∀X, Y∈𝕆 : X ≠ Y ∧ |mX - mY| < ε, ∃M, N∈𝕆 : M ≠ N ∧ |mM - mN| < ε ∧ |mX - mM| > 2ε ⇒ XDY > MDN

注意：XDY = 0 ⇏ tX = tY。

瞬时量化差异

X在第t秒的瞬时量化差异为 limh→0+ X(t)DX(t + h)，也可以写成 DX(t)。瞬时量化差异描述了一个物体在某一时刻变化的强度。

对于一个不受外力的铁块X，DX(t)通常非常小，几乎为0。

对于一罐正在被液压机缓慢压扁的易拉罐Y，DY(t)会比0稍大一点。

对于一个被子弹打碎的玻璃瓶Z，DZ(t)在开始的时候很小，被子弹击碎时突然增大，待玻璃散落一地时又会变小。

不难注意到，瞬时量化差异和“熵”的导数有关系：

|dS/dt|增大时，DX(t)会增大。

全同碰撞定理

在讨论全同论前，我们假设了三个前提。通过这些前提，我们就可以推导出全同碰撞定理：

∀X∈𝕆 : X ≠ 𝟎, ∀n∈ℤ+, S = { Y∈𝕆 : tY = tX ∧ YDX = 0 }, card(S) ≥ n.

全同碰撞定理是指在任意时刻下，对于该时刻下的任何质量有限但不为0的物体，一定存在无数个与其全同但在空间中不重叠的物体。

举个粒子，现在桌子上有一个微虫洞模块，那么我一定能在宇宙中找到另外无数多个微虫洞模块，哪怕最近的一个位于10^10^10^...光年开外，这些微虫洞模块都与彼此全同。

不单止是微虫洞模块，一个铁块，一把小刀，根据全同碰撞定理，你就一定会在同一时刻的宇宙里的某处，发现另一个全同的铁块、另一把全同的小刀。

全同碰撞定理很容易得出来。当某一时刻下的宇宙是空间无限，且质能无限还分布均匀的，在宇宙中形成了一个物体X，那么总是存在一个非常非常小的概率P，在宇宙另一处“误打误撞”形成了一个与物体X全同的物体Y。

由于宇宙是空间无限的，我们可以理解为“每时每刻宇宙都在尝试无数次，生成全同的物体”，也就是 ∞×P。无论P有多小，只要 P ≠ 0，宇宙的成功次数就一定趋向于无穷。

试想一下，宇宙中的两颗新星爆发了，炸出许多重元素。刚好这些铁原子组合在一起，刚好形成的块铁的原子排布都一模一样，又刚好所有的离域电子的排布也一致，甚至刚好形成于同一时刻下……一连串“刚好”发生的概率可想而知低得可怜，可是宇宙每秒钟都有无数枚新星爆炸，每秒钟都有无数块铁形成。在无数次尝试下，这些“刚好”总是会发生，甚至也发生了无数次。

宇宙密度

物体X与它的全同物体的总质量，比上宇宙时空里总质量，就是X的宇宙密度，写作 Den X（或者Den(X)）。

    在 Den X = n 里：
  • X∈𝕆;
  • n∈[0, 1].
